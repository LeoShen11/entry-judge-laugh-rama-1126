Entry for the [Make the AI Judge Laugh](https://make.fun/c/u-rama-melon-make-the-ai-judge-laugh-302d0825) bounty on make.fun.

`main.py` writes a single office-life joke — one line, under 200 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then validates it (single line, 1–200 characters, not blank) and reads it back to prove the file on disk matches exactly.

The joke:

> Our office printer only jams five minutes before a deadline — apparently it reads my calendar better than I do.
